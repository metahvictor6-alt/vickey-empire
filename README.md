# Vickey Empire

A minimal Android app project named "Vickey Empire".

How to run in Android Studio
1. Install Android Studio.
2. Open the repository folder in Android Studio.
3. Let Gradle sync complete.
4. Connect a physical Android device or start an emulator.
5. Click Run > Run 'app'.

Build APK
- In Android Studio: Build > Build Bundle(s) / APK(s) > Build APK(s)
- The APK will be generated under:
  `app/build/outputs/apk/debug/app-debug.apk`

App details
- App name: Vickey Empire
- Package: `com.vickey.empire`
- Target: Android 5.0+ (API 21+)

This project is a simple demonstration app with a single screen and a button that opens a web page.
